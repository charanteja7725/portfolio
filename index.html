03 / INDIVIDUAL FULL-STACK BUILD
HB
Heaven-BusREAL-TIME BUS BOOKING
INDIVIDUAL FULL-STACK BUILD03

Heaven-Bus

A real-time bus-booking system built around seat contention: several passengers may try to reserve the same seat while abandoned holds must expire safely.

PROBLEM / CONTEXT

Seat selection, payment callbacks and hold expiry can race, creating double bookings or seats stuck unavailable.

IMPLEMENTATION

Implemented five-minute seat holds with MongoDB transactions, payment verification and compensating refund handling. Ask Jarvis combines route search with issue-specific support contacts; Ollama provides free-form answers in local development while critical booking facts stay deterministic.

KEY FEATURES
  • Seat search, live seat map and timed holds
  • Race-safe booking and payment/refund handling
  • Passenger journey tracking and admin trip/refund controls
  • Ask Jarvis for trip discovery and relevant support numbers
TECHNOLOGY
ReactTypeScriptNode.jsExpressMongoDBSocket.IOOllamaVitestPlaywright
MY ROLE / PROJECT CONTEXT

Individual project build.

ENGINEERING TAKEAWAY

Booking workflows need clear ownership of inventory state and recovery paths for expiry, duplicate payments and concurrent requests.
